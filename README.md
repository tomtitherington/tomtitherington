the component worked yesterday.

this morning
it has decided
it no longer believes
in props.

I add a useEffect.

then another.

soon there are six of them
watching each other

the page rerenders
forty-seven times.

the fan starts screaming.

somewhere
a senior engineer says
“we should probably move this
into context.”

I close the laptop.

somewhere beyond all this
the state is still.

and it looks
server-rendered.
